## 🌟 Why this exists

The open-source AI ecosystem is growing extremely quickly.

New agents, models, MCP servers, frameworks, tools, and skills are being released every day. Finding useful projects is becoming increasingly difficult.

This repository aims to make that discovery easier.

Instead of searching through hundreds of GitHub repositories, you can discover useful open-source AI projects organized in one place.

## 🔎 What's inside?

### 🤖 AI Agents

Real-world autonomous and semi-autonomous AI agents.

- Coding agents
- Research agents
- Browser agents
- DevOps agents
- Data analysis agents
- Productivity agents
- Customer support agents
- Multi-agent systems

### 🧠 Open-Weight Models

Useful open-weight models for building AI applications.

- LLMs
- Vision models
- Multimodal models
- Embedding models
- Speech models
- Small/local models

### 🔌 MCP Servers

Model Context Protocol servers that connect AI systems to external tools and data.

- Developer tools
- Databases
- Cloud platforms
- Search
- Productivity
- APIs
- Filesystems

### 🛠️ Agent Frameworks

Frameworks for building AI agents and agentic applications.

### 🧩 Agent Skills

Reusable capabilities that can be added to AI agents.

### 🚀 Real-World Projects

Interesting open-source applications that demonstrate practical AI use cases.

## 🧑‍💻 Hacktoberfest 2026

This repository welcomes contributors participating in Hacktoberfest 2026.

The goal is **meaningful open-source contribution**, not simply increasing the number of pull requests.

Good contributions include:

- Adding useful projects
- Improving documentation
- Building useful features
- Creating examples
- Improving search and discovery
- Adding tests
- Improving developer experience
- Fixing bugs
- Improving automation

Low-effort, duplicate, spam, or automatically generated submissions without meaningful review may be rejected.
