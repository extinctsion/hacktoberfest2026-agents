# 🤝 Contributing

Thank you for contributing to Open Source AI Agents!

There are many ways to contribute.

## Ways to contribute

### Add a project

You can submit:

- AI agents
- Open-weight models
- MCP servers
- Agent frameworks
- Agent skills
- AI developer tools
- Tutorials

### Improve documentation

You can:

- Fix typos
- Improve descriptions
- Add examples
- Improve tutorials
- Fix broken links

### Build features

You can help with:

- Website
- Search
- Automation
- GitHub integrations
- Validation
- Statistics

---

## 📝 Adding a project

Before submitting a project:

1. Search the repository for duplicates.
2. Make sure the project is open source.
3. Verify the repository URL.
4. Add the project to the appropriate category.
5. Follow the existing formatting.
6. Open a pull request.

---

## 🚫 Low-quality contributions

The following may be rejected:

- Spam
- Duplicate submissions
- Broken links
- Unrelated projects
- Empty changes
- Automatically generated low-quality content
- Projects without meaningful relevance to the repository

---

## 🚀 Hacktoberfest

Hacktoberfest contributors are welcome.

Please focus on meaningful contributions that improve the project for future users.

Quality is more important than the number of pull requests.
